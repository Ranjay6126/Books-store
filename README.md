# Books-store
Books store web Application using MongoDB, Express.js, React.js and Node.js

📚 Books Store Web Application

A full-stack Books Store Web Application built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js).
This application allows users to manage books with features like adding, viewing, updating, and deleting books from the database.

🚀 Features

📖 Add new books to the collection

📚 View a list of all available books

✏️ Update book details

❌ Delete books from the store

🔍 View detailed information about a book

🌐 Full stack CRUD application using MERN

⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/yourusername/books-store.git
cd books-store
2️⃣ Backend Setup
cd backend
npm install
npm start
3️⃣ Frontend Setup
cd frontend
npm install
npm start
🔗 API Endpoints
Method	Endpoint	Description
GET	/books	Get all books
GET	/books/:id	Get single book
POST	/books	Add a new book
PUT	/books/:id	Update book
DELETE	/books/:id	Delete book
